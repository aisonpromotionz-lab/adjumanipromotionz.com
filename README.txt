AISON PROMOTIONZ WEBSITE

ADMIN POSTER PUBLISHING
- Sign in to Admin workspace (demo code 2468).
- Enter a poster title, choose a category, select an image and add details.
- Press Publish poster. The poster appears in the public Services & Updates section.
- Posters are stored in this browser's local storage.

IMPORTANT
- This is a static website demo. Posters appear for visitors using the same browser/device profile only.
- To publish posters for all clients online, connect the website to shared hosting, a database/file-storage service and secure administrator authentication.

ADMIN POSTER PUBLISHING (VISIBLE IN ADMIN WORKSPACE)
After signing in with demo code 2468, scroll down inside the Admin section. You will see a box titled "Publish a poster" below the enquiry notes. Select an image, enter a title, add details and press "Publish poster". The poster is shown in the public Updates section.

This demo stores posters only in the same browser/device. It does not synchronise to other visitors. For a live public shared gallery, connect a database and image storage with secure administrator login.

DELETE A PUBLISHED UPDATE
- Sign in to the Administrator workspace using access code 2468.
- Find the "Manage published updates" area below "Publish a poster".
- Select Delete beside the update you want to remove.
- Confirm the deletion. The post is removed from the public Updates page in this browser.
